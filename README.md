# Jaringan Komputer — Presentasi Interaktif

Presentasi kelas tentang **Jaringan Komputer**: LAN, MAN, WAN, dan Internet.

- **10 slide** interaktif (navigasi panah / spasi / klik jalur bawah, `F` untuk layar penuh)
- Peta Nusantara & peta dunia (data Natural Earth) dengan animasi paket data
- Slide perangkat jaringan (NIC, kabel, switch, router, modem, access point) + alur kerja
- Responsif di berbagai perangkat

## Cara menjalankan
Buka `index.html` di browser (atau akses versi online via GitHub Pages).

## File
- `index.html` — presentasi utama (salinan dari `Jaringan Komputer.html`)
- `Jaringan Komputer.html` — sumber presentasi
- `peta-dunia.html` — data peta dunia (Natural Earth 50m)
